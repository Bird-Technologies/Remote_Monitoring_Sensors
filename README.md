# Remote_Monitoring_Sensors

[![Python 3.12](https://img.shields.io/badge/python-3.12-&?labelColor=3E434A&colorB=006281&logo=python)](https://www.python.org/downloads/release/python-3127/)

## Directory

* **[bird_4042e.py](./bird_4042E.py)**  
An example of what the foundation driver code might look like contained in a single file format. This code can be imported and used in other examples. 
* **[ex01_sample_aggregate_power_and_vswr.py](./ex01_sample_aggregate_power_and_vswr.py)**  
This example shows how to poll the 4042E remote power monitor/sensor for forward power, reflected power, and VSWR information.
* **[ex02_modify_configuration_settings.py](./ex02_modify_configuration_settings.py)**  
This example shows how to modify the 4042E remote power monitor/sensor configuration settings.
* **[ex03_check_max_speed_for_getting_forward_power.py](./ex03_check_max_speed_for_getting_forward_power.py)**  
This example is used to get a feel for how quickly the code will allow the 4042E to respond to GETs of forward power.
